I made my site look like my old Game Boy Color

I had the grape one: the purple plastic, the dark bezel, the little red power light. When it came time to build a personal site, that was the object I kept coming back to.

So the site is the console. Purple body, dark bezel, and a dim screen where everything lives. Links behave like a game menu: point at one and a cursor appears.
